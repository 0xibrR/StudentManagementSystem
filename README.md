# Student Management System

نظام مكتبي لإدارة الطلاب والدفعات والحضور والغياب، مبني باستخدام Java وJavaFX وMySQL. يوفّر واجهة باللغتين العربية والإنجليزية، مع تقارير قابلة للتصدير.

## الوظائف

- إنشاء حساب وتسجيل الدخول، مع تذكّر آخر جلسة على الجهاز.
- إدارة بيانات الطلاب: الاسم، سنة الميلاد، الهاتف، تاريخ الالتحاق والملاحظات.
- تحديد أيام الدوام الأسبوعية وتاريخ بدء الجدول لكل طالب.
- تسجيل الحضور والغياب والحالات الأخرى للطلاب المجدولين في يوم محدد، مع إمكانية حفظ السجلات وتحديثها.
- تسجيل الدفعات النقدية أو البنكية أو المقسّمة بينهما، وعرض سجل دفعات الطالب.
- لوحة رئيسية بإحصاءات الطلاب والدفعات والإيرادات والمتبقي.
- تقارير الطلاب والدفعات بصيغتي PDF وCSV، وتصدير تقارير الحضور بصيغة CSV، بأسماء ملفات تتضمن نوع التقرير والتاريخ والوقت.
- التبديل بين العربية والإنجليزية من داخل التطبيق.

## التقنيات والمكتبات

- Java مع JavaFX 27 وFXML وCSS.
- MySQL مع MySQL Connector/J 9.7.0.
- OpenPDF 2.2.2 لإنشاء تقارير PDF.
- لا يوجد حاليًا Maven أو Gradle؛ ملفات المكتبات موجودة ضمن مجلد `libraries` وإعداد المشروع موجّه إلى IntelliJ IDEA.

## المتطلبات

- JDK متوافق مع JavaFX 27.
- IntelliJ IDEA أو بيئة Java تدعم تشغيل JavaFX.
- MySQL Server يعمل محليًا أو على خادم يمكن الوصول إليه.

## إعداد قاعدة البيانات

1. أنشئ قاعدة البيانات في MySQL:

   ```sql
   CREATE DATABASE student_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. اضبط متغيرات البيئة التالية عند تشغيل التطبيق:

   - `DB_USER`: اسم مستخدم MySQL.
   - `DB_PASSWORD`: كلمة مروره. إذا كانت كلمة المرور فارغة في إعدادك المحلي، عيّن المتغير إلى نص فارغ.
   - `DB_URL`: اختياري؛ القيمة الافتراضية هي `jdbc:mysql://localhost:3306/student_management`.

   مثال في PowerShell للجلسة الحالية:

   ```powershell
   $env:DB_USER = "root"
   $env:DB_PASSWORD = "your-password"
   # اختياري عند استخدام عنوان قاعدة بيانات مختلف:
   $env:DB_URL = "jdbc:mysql://localhost:3306/student_management"
   ```

   أو أضف المتغيرات من **Run > Edit Configurations > Environment variables** في IntelliJ. لا تضع بيانات الدخول الحقيقية في ملفات المشروع أو Git.

## فتح المشروع وتشغيله في IntelliJ IDEA

1. افتح مجلد المشروع في IntelliJ IDEA.
2. من **File > Project Structure > Project** اختر JDK متوافقًا مع JavaFX 27.
3. أضف ملفات المكتبات إلى المشروع من **File > Project Structure > Libraries**:
   - JavaFX: مجلد `libraries/javafx-sdk-27/lib`.
   - MySQL: الملف `libraries/mysql-connector-j-9.7.0/mysql-connector-j-9.7.0.jar`.
   - OpenPDF: الملف `libraries/openpdf-2.2.2.jar`.
4. أنشئ إعداد تشغيل من الفئة `App`، وأضف إلى **VM options** (عدّل المسار إذا كان المشروع في مكان آخر):

   ```text
   --module-path "C:\Users\<username>\IdeaProjects\StudentManagementSystem\libraries\javafx-sdk-27\lib" --add-modules javafx.controls,javafx.fxml
   ```

5. أضف متغيرات قاعدة البيانات إلى إعداد التشغيل كما في القسم السابق، ثم شغّل `App`.

عند بدء التشغيل، ينشئ التطبيق جداول النظام المطلوبة إذا لم تكن موجودة. لا ينشئ بيانات تجريبية تلقائيًا؛ أنشئ حسابًا من شاشة التسجيل ثم أضف بياناتك من الواجهة.

## بنية المشروع

```text
src/
├── App.java                 # نقطة تشغيل تطبيق JavaFX
├── controllers/             # منطق شاشات التطبيق
├── database/                # الاتصال بقاعدة البيانات وعمليات المستودعات
├── models/                  # نماذج البيانات والجلسة
├── reports/                 # إنشاء PDF وتصدير CSV
├── ui/                      # الترجمة وإطار النافذة المخصص
├── css/                     # تنسيق الواجهة
└── views/                   # شاشات FXML
libraries/                   # JavaFX وموصل MySQL وOpenPDF
```

## جداول قاعدة البيانات

ينشئ التطبيق الجداول التالية:

- `users`: حسابات المستخدمين.
- `students`: الطلاب المرتبطون بحساب المستخدم.
- `payments`: دفعات الطلاب والمبالغ النقدية والبنكية.
- `student_schedules` و`student_schedule_days`: فترات وأيام دوام الطلاب.
- `attendance`: حالة حضور كل طالب في كل تاريخ.

تُعزل سجلات كل مستخدم بحسب حسابه، وتُحذف السجلات التابعة عند حذف السجل الأب وفق قيود قاعدة البيانات.

## الأمان والبيانات

- تُحفظ كلمات مرور الحسابات الجديدة باستخدام PBKDF2-HMAC-SHA256 مع ملح عشوائي.
- عند تسجيل الدخول بنجاح لحساب قديم ذي كلمة مرور نصية، يحوّلها التطبيق تلقائيًا إلى صيغة التجزئة.
- بيانات اتصال MySQL تؤخذ من متغيرات البيئة ولا ينبغي إضافتها إلى المستودع.
- خذ نسخة احتياطية من قاعدة البيانات قبل نقلها أو إجراء تغييرات يدوية عليها.

## استكشاف الأخطاء

- **Database configuration is missing**: تحقق من وجود `DB_USER` و`DB_PASSWORD` في إعداد التشغيل نفسه.
- **تعذّر الاتصال بـ MySQL**: تأكد من تشغيل الخادم، وصحة اسم القاعدة والمستخدم وكلمة المرور، ومن أن `DB_URL` يشير إلى العنوان الصحيح.
- **JavaFX runtime components are missing**: راجع مسار JavaFX في `--module-path` وتأكد من وجود `javafx.controls` و`javafx.fxml` في `--add-modules`.
- **تعذّر تحميل تقرير PDF أو CSV**: تحقق من توفر صلاحية الكتابة إلى المجلد المختار في نافذة التصدير، ومن وجود مكتبات المشروع على classpath.
